\section{Task Description}

Image quality assessment (IQA) aims to predict how people perceive the quality of an image. In the no-reference setting, a model must estimate this quality without access to a pristine reference image. A conventional no-reference metric receives only the distorted image, even though the relationship between visible image features and perceived quality may depend on the kind of degradation present. For example, blur, noise, and compression produce different artefacts and may therefore require different interpretations of the same visual representation.

The goal of this project is to determine whether an IQA model agrees more closely with human judgements when it is additionally told which broad family of distortion it is observing. The condition is a coarse distortion group rather than a dataset-specific distortion label. The groups used in the project are blur, noise, compression, colour, tone, spatial, generative, and authentic. The authentic group represents photographs that were not degraded artificially. This shared vocabulary makes it possible to use a consistent condition across datasets whose original distortion annotations differ.

The principal comparison is between an image-only baseline and a conditioned model built on the same frozen visual representation. Both models predict a continuous subjective quality score, scaled to the interval $[0,1]$, where a higher value denotes better quality. Performance is measured by the agreement between predicted and human scores using Spearman's rank correlation coefficient (SRCC) and Pearson's linear correlation coefficient (PLCC). The study also includes shuffled, deliberately incorrect, zeroed, and permuted-training conditions. These controls are needed to distinguish a gain caused by useful distortion information from one caused merely by additional model parameters or correlations specific to a dataset.

Evaluation must avoid content leakage. Images derived from the same pristine reference are kept entirely in either the training or validation split, since placing different distortions of the same source image on both sides can allow the model to recognise image content instead of learning image quality. When multiple datasets are used, results are examined per dataset and sampling is balanced so that the largest dataset does not dominate the experiment. In addition to predictive correlations, the comparison records model size, computational cost, inference latency, throughput, and peak GPU memory. The resulting task is therefore not only to maximize correlation with human opinion, but to establish through controlled experiments whether conditioning on distortion families provides a genuine and practically useful improvement over image-only IQA.

\section{Experimental Setup}

\subsection{Baseline Architecture}

We use the image-only model from the original project repository as the common baseline for all conditioning approaches. An input image is converted to RGB, resized with bicubic interpolation to the spatial resolution required by the selected CLIP model, and normalized using the CLIP channel statistics. It is then passed through a pretrained CLIP vision transformer. The encoder is kept in evaluation mode and all of its parameters are frozen, so only the quality-prediction head is optimized. The baseline uses the pooled global representation produced by CLIP rather than its individual patch tokens.

The quality head consists of layer normalization, a linear projection to 256 hidden units, a GELU activation, dropout with probability 0.1, and a final linear layer that outputs one scalar. For a pooled image embedding $z \in \mathbf{R}^{d}$, the prediction can be written as
\[
\hat{y} = W_2\,\mathrm{Dropout}\!\left(\mathrm{GELU}\!\left(W_1\mathrm{LayerNorm}(z)+b_1\right)\right)+b_2.
\]
No output activation is applied; the head directly regresses the normalized subjective quality score. This deliberately simple architecture provides a stable reference against which the contribution of each conditioning mechanism can be measured.

We evaluate the common baseline and conditioned models with two CLIP encoder sizes. CLIP-Base uses the ViT-B/16 architecture at $224\times224$ pixels and produces a 768-dimensional pooled embedding. CLIP-Large uses ViT-L/14 at $336\times336$ pixels and produces a 1024-dimensional embedding. The resulting baseline heads contain 198,657 and 264,705 trainable parameters, respectively; the substantially larger vision encoders remain frozen in both cases. The text-conditioning backbone ablation additionally uses frozen SigLIP-L/16 at $256\times256$, while the classifier and ARNIQA sections introduce their auxiliary encoders locally because they are not part of the common baseline.

\subsection{Training Protocol}

Unless a later experiment section states otherwise, we use the hyperparameters of the reference baseline. The regression head is trained for five epochs with batches of 32 images. Optimization uses AdamW with a learning rate of $10^{-3}$ and the Smooth L1 loss with $\beta=0.1$. The hidden width is 256, dropout is 0.1, and random seeds for Python, NumPy, and PyTorch are fixed to 0. For a single dataset, training examples are randomly shuffled; for a joint training table, inverse-frequency sampling by dataset gives each corpus equal expected influence regardless of its size.

Within each training dataset, 20\% of the data is held out for validation. \subsection{Evaluation Protocol}

We report SRCC and PLCC separately for every dataset. For multi-dataset experiments, macro SRCC and macro PLCC are computed by averaging the per-dataset correlations rather than pooling samples whose subjective scales and contents are not directly comparable; the worst per-dataset SRCC is also recorded. PIPAL is additionally evaluated using mean within-reference SRCC because its Elo scores rank restorations of the same source image and do not define an absolute ordering across different references. Conditioned models are compared with an independently trained image-only baseline under the same backbone, data split, and optimization settings. The intervention tests with wrong, shuffled, zeroed, and training-permuted conditions are reported in the corresponding experiment sections.

Unless a section explicitly identifies an early diagnostic result, we restore the checkpoint with the highest validation macro SRCC before testing. The initial KADID-10k text-fusion comparison instead reports final-epoch means, which is why its baseline numbers should not be interchanged with the best-checkpoint KADID-10k baselines used in later sections.

\subsection{Efficiency Measurements}

Alongside correlation, we report total parameters, estimated GFLOPs, median per-image latency, throughput in images per second, and peak GPU memory from the saved experiment artifacts. Throughput and latency are hardware- and implementation-dependent and therefore support comparisons within the recorded benchmark environment rather than universal deployment guarantees. We call a model Pareto-optimal with respect to throughput and test macro SRCC when no other measured model is both faster and more accurate.

\section{Text Conditioning}

\subsection{Method}

In the text-conditioned experiments, every distortion group is represented by a short natural-language instruction describing the artefacts that should be assessed. For example, the blur prompt asks the model to assess lost sharpness, defocus, motion blur, and missing fine detail, while the authentic prompt asks for the overall perceptual quality of a real photograph. We encode these instructions once with the frozen text tower paired with the selected CLIP vision encoder. Both the pooled image feature and the text feature are layer-normalized and projected to 256 dimensions, so the text branch does not modify the frozen CLIP backbone.

We examined three elementary fusion rules. Concatenation gives the regressor $[v,t]$, interaction fusion gives it $[v,t,v\odot t]$, and the residual model adds a text-dependent correction to an unconditional image score. Here $v$ and $t$ denote the projected image and prompt embeddings and $\odot$ denotes elementwise multiplication. The image-only baseline retains the original pooled-feature head. The interaction term proved the most reliable of these alternatives and was therefore used in the later multi-dataset and multi-view experiments.

\subsection{MOS Alignment and Dataset-Aware Objectives}

Even after min--max normalization, MOS values from different datasets do not necessarily share the same perceptual origin, spacing, or noise level. A single regression loss can therefore give conflicting gradients for images of similar perceptual quality. We tested a lightweight MDTVSFA-inspired approximation that learns a monotonic sigmoid calibration for each training dataset and adds within-dataset ranking, as well as a faithful three-stage adaptation with a shared relative score, a shared four-parameter logistic perceptual mapping, and a dataset-specific affine alignment in the original score units. At test time an unseen dataset has no learned alignment layer and therefore uses the shared latent or perceptual score.

\subsection{Fusion-Head and Capacity Ablations}

Beyond concatenation and elementwise interaction, we tested several ways to make the condition act on spatial or channelwise features. FiLM predicts bounded featurewise scales and shifts from the text vector. Direct patch scoring predicts and weights quality at every frozen CLIP token, while text-conditioned patch scoring also uses $[p_i,t,p_i\odot t]$ to determine the weights. The two residual patch heads preserve a pooled global scorer and add a gated patch correction, either without text or with text in both the patch scorer and gate. Cross-attention uses the text vector as a four-head query over projected patch tokens and gates its correction to the global interaction score. A final adapter variant places a zero-initialized 64-dimensional residual bottleneck on the pooled visual feature before the standard interaction head.

\subsection{Backbone and Multi-View Experiments}

The principal text-conditioning experiment used KADID-10k, SPAQ, and AIGCIQA2023. It contains 18,945 training images and 4,705 validation images, sampled with equal expected weight per dataset. GFIQA-20k, PIPAL, TID2013, CSIQ, CID2013, KonIQ-10k, CLIVE, AGIQA-3K, and UHD-IQA form the nine-dataset test macro average. Central results are averaged over three repeated runs.

The five-view model was introduced because a single center crop can remove local distortions or rescale them until they are difficult to recognize. It encodes one aspect-preserving global crop and four local tiles with the frozen CLIP encoder. The text interaction features $[v_i,t,v_i\odot t]$ determine a learned softmax weight for each view; the weighted visual representation is then fused with the prompt by the same interaction rule. The image-only multi-view control uses the same five views and learned weighting but omits the text branch, while a widened control approximately matches the conditioned head's parameter count.

Thus CLIP-Base is about 3.5 times smaller, uses 3.4 times less peak memory, and is 7.6 times faster in this comparison. Five-view SigLIP-Large reaches the best test SRCC, 0.6699, but uses 316.88M parameters and 1304.0 MB while running at 22.68 images/s; the CLIP-Base result is only 0.0087 lower and is 3.5 times faster.

Across the whole text workstream, the reported test macro SRCC rises from 0.4783 for the first KADID-only CLIP-Base baseline to 0.6612 for the final calibrated five-view CLIP-Base model. This 0.1829 end-to-end gain demonstrates the value of the complete development path, but it is not a conditioning-only effect because the training mixture, checkpoint selection, and view representation also changed. The controlled conclusions are narrower: pooled text improves over pooled image-only under the same three-dataset setup, and five-view text improves over the matched five-view image-only control. The final CLIP-Base system is slower than the original single-view baseline, but it provides a notably stronger accuracy--efficiency balance than the tested large-backbone alternatives, which makes it the most attractive configuration for high-throughput use when the distortion-group prompt is available.

\section{Dataset Label Conditioning}

\subsection{Method}

Dataset label conditioning uses the known coarse distortion group directly rather than expressing it as natural language. Each of the eight groups is mapped to a learned 32-dimensional embedding. During training, 10\% of the conditions are zeroed so that the head also learns an unconditional fallback. The CLIP visual encoder remains frozen, and only the group embedding, fusion layers, and quality head are optimized.

We investigated several ways to inject the group embedding. Concatenation appends it to the normalized pooled CLIP representation. Additive fusion uses a zero-initialized linear projection to add a label-dependent offset in the 768-dimensional visual space. Input FiLM predicts an identity-initialized scale and shift for the normalized CLIP feature, whereas hidden FiLM applies the same operation after the first hidden activation. The residual-gate model preserves a complete unconditional quality scorer and adds a label-dependent correction multiplied by a learned sigmoid gate. The rank-4 hypernetwork generates a low-rank update to the first regression layer and reduces the shared hidden width to remain close to the baseline parameter budget. Finally, label-guided patch attention projects the group embedding into a query over frozen CLIP patch tokens, with the pooled token providing the zero-condition fallback. In all results in this section, the ground-truth dataset group is supplied at inference time, so these experiments measure the value of an oracle label rather than the performance of an automatic distortion recognizer.

Of particular interest is the rank-4 hypernetwork: instead of modifying every visual channel directly, it uses the label embedding to generate four coefficients for a low-rank update to the first regression layer. \section{Classifier Label and Feature Conditioning}

\subsection{Distortion Classifier}

Oracle group labels are unavailable for arbitrary test images, so we trained an ImageNet-pretrained ResNet-18 to recognize the eight distortion groups. Its final classification layer was replaced by an eight-class output layer, and the network was optimized with class-weighted cross entropy, AdamW, a learning rate of $10^{-4}$, weight decay $10^{-4}$, and batches of 64. The best validation accuracy was 88.6\%. We then supplied either the classifier's hard argmax label or its soft class-probability vector to a CLIP-Base quality head. In the frozen setting the classifier weights were fixed; in the joint setting the classifier and IQA head were optimized together with loss $L=L_{\mathrm{IQA}}+0.25L_{\mathrm{cls}}$.

\subsection{Predicted-Label Results}

Table~\ref{tab:classifier-labels} compares predicted labels with both an oracle-label upper bound and a zero-condition control using the same one-hidden-layer concatenation head. Ground-truth labels improved test SRCC by only 0.0044 over the zero-condition control, so even a perfect group classifier leaves little available gain for this head. Predicted labels then introduce structured condition errors, while the soft vector mainly represents uncertainty among the same eight categories and still does not encode distortion severity. The quality regressor therefore receives extra information optimized for class separation rather than for ranking quality within a class. For every image, ARNIQA aggregates five spatial crops at full scale and five at half scale into a 4096-dimensional feature. This vector is layer-normalized, projected through a 32-dimensional GELU bottleneck, and concatenated with the frozen pooled CLIP feature before quality regression. This is no longer a minimal label-conditioning method: it adds a second IQA-oriented visual encoder and ten-crop processing, so its accuracy and computational cost must be interpreted separately from the lightweight group conditions.

Text and oracle dataset labels provide the best accuracy--efficiency balance because their condition vectors are computed once or retrieved by index and add little cost to the frozen CLIP-Base encoder. ARNIQA features are a stronger automatically extracted condition and produce a large in-domain gain, but the second backbone and ten-crop evaluation make them the most memory-intensive CLIP-Base approach. Thus increasingly rich automatic conditions improve the available quality signal, but they also move the model away from the lightweight-conditioning objective.

The most successful architectural change is to preserve global representations while adding complementary localized evidence. Direct patch-score weighting discards too much global context, whereas the five-view text model encodes a full pooled representation for one global crop and four local crops. This explains why five-view conditioning improves all three tested backbone families and why CLIP-Base can match the accuracy range of much larger encoders. Among the compared models, five-view SigLIP-Large gives the highest test SRCC of 0.6699, but calibrated five-view CLIP-Base reaches 0.6612 with roughly one quarter of the parameters, one third of the peak memory, and more than three times the throughput.

\section{Conclusion}

The experiments show that distortion conditioning can improve no-reference IQA, but its effectiveness depends on both the information content of the condition and the way the visual representation is preserved. Natural-language interaction consistently improves a matched pooled CLIP-Base baseline, survives prompt paraphrasing, and degrades under wrong or shuffled prompts, demonstrating genuine use of condition semantics. Oracle dataset labels also help, with residual gating and a rank-4 hypernetwork providing strong and inexpensive fusion mechanisms. By contrast, predicted class labels are too coarse to improve quality ranking reliably, while continuous classifier and ARNIQA features contain more useful information but generalize unevenly or require substantially more computation.

The selected training mixture combines controlled, authentic, and generative distortions without the transfer loss observed after adding PIPAL ranking or the screened GFIQA expansion. Dataset-specific MOS calibration is well motivated by incompatible subjective scales and slightly improves some settings, but neither the approximate nor faithful MDTVSFA-style objective replaces ordinary global interaction as the best pooled approach. Head-capacity controls likewise show that the gain is not explained by parameter count alone. The largest improvement comes from combining text interaction with global-plus-local five-view features, which retains image context while exposing localized artefacts.

For a high-throughput system with known distortion metadata, the dataset-label residual gate is the most efficient strong option. When a natural-language condition is preferred, pooled CLIP-Base interaction adds almost no inference cost and gives a clear transfer gain. When maximum accuracy is more important, the five-view CLIP-Base text model offers the best overall compromise: it approaches the strongest SigLIP-Large result and exceeds the tested CLIP-Large alternatives while remaining far smaller, faster, and less memory-intensive. The remaining practical challenge is to obtain a reliable condition for an arbitrary image without losing the benefit through classification errors or adding the cost of a second heavy visual encoder.
