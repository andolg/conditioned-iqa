\section{Task Description}

Image quality assessment (IQA) aims to predict how people perceive the quality of an image. In the no-reference setting, a model must estimate this quality without access to a pristine reference image. A conventional no-reference metric receives only the distorted image, even though the relationship between visible image features and perceived quality may depend on the kind of degradation present. For example, blur, noise, and compression produce different artefacts and may therefore require different interpretations of the same visual representation.

The goal of this project is to determine whether an IQA model agrees more closely with human judgements when it is additionally told which broad family of distortion it is observing. The condition is a coarse distortion group rather than a dataset-specific distortion label. The groups used in the project are blur, noise, compression, colour, tone, spatial, generative, and authentic. The authentic group represents photographs that were not degraded artificially. This shared vocabulary makes it possible to use a consistent condition across datasets whose original distortion annotations differ.

The principal comparison is between an image-only baseline and a conditioned model built on the same frozen visual representation. Both models predict a continuous subjective quality score, scaled to the interval $[0,1]$, where a higher value denotes better quality. Performance is measured by the agreement between predicted and human scores using Spearman's rank correlation coefficient (SRCC) and Pearson's linear correlation coefficient (PLCC). The study also includes shuffled, deliberately incorrect, zeroed, and permuted-training conditions. These controls are needed to distinguish a gain caused by useful distortion information from one caused merely by additional model parameters or correlations specific to a dataset.

Evaluation must avoid content leakage. Images derived from the same pristine reference are kept entirely in either the training or validation split, since placing different distortions of the same source image on both sides can allow the model to recognise image content instead of learning image quality. When multiple datasets are used, results are examined per dataset and sampling is balanced so that the largest dataset does not dominate the experiment. In addition to predictive correlations, the comparison records model size, computational cost, inference latency, throughput, and peak GPU memory. The resulting task is therefore not only to maximize correlation with human opinion, but to establish through controlled experiments whether conditioning on distortion families provides a genuine and practically useful improvement over image-only IQA.

\section{Experimental Setup}

\subsection{Baseline Architecture}

We use the image-only model from the original project repository as the common baseline for all conditioning approaches. An input image is converted to RGB, resized with bicubic interpolation to the spatial resolution required by the selected CLIP model, and normalized using the CLIP channel statistics. It is then passed through a pretrained CLIP vision transformer. The encoder is kept in evaluation mode and all of its parameters are frozen, so only the quality-prediction head is optimized. The baseline uses the pooled global representation produced by CLIP rather than its individual patch tokens.

The quality head consists of layer normalization, a linear projection to 256 hidden units, a GELU activation, dropout with probability 0.1, and a final linear layer that outputs one scalar. For a pooled image embedding $z \in \mathbf{R}^{d}$, the prediction can be written as
\[
\hat{y} = W_2\,\mathrm{Dropout}\!\left(\mathrm{GELU}\!\left(W_1\mathrm{LayerNorm}(z)+b_1\right)\right)+b_2.
\]
No output activation is applied; the head directly regresses the normalized subjective quality score. This deliberately simple architecture provides a stable reference against which the contribution of each conditioning mechanism can be measured.

We evaluate the baseline and conditioned models with two CLIP encoder sizes. CLIP-Base uses the ViT-B/16 architecture at $224\times224$ pixels and produces a 768-dimensional pooled embedding. CLIP-Large uses ViT-L/14 at $336\times336$ pixels and produces a 1024-dimensional embedding. The resulting baseline heads contain 198,657 and 264,705 trainable parameters, respectively; the substantially larger vision encoders remain frozen in both cases.

All releases are converted to a common table containing the image path, original subjective score, normalized score, dataset, reference, distortion type, severity level, and distortion group. Scores are min--max normalized separately for each dataset to $[0,1]$, with larger values always denoting better quality; consequently, datasets that publish DMOS in the opposite direction are inverted during preparation. The original scores are retained for traceability.

\subsection{Training Protocol}

Unless a later experiment section states otherwise, we use the hyperparameters of the reference baseline. The regression head is trained for five epochs with batches of 32 images. Optimization uses AdamW with a learning rate of $10^{-3}$ and the Smooth L1 loss with $\beta=0.1$. The hidden width is 256, dropout is 0.1, and random seeds for Python, NumPy, and PyTorch are fixed to 0. For a single dataset, training examples are randomly shuffled; for a joint training table, inverse-frequency sampling by dataset gives each corpus equal expected influence regardless of its size.

Within each training dataset, 20\% of the data is held out for validation. Synthetic datasets are split by pristine reference, ensuring that every distorted version of a source image remains on the same side of the split. Generated-image datasets are grouped by prompt where prompt metadata is available, while authentic datasets without shared references are split by image. The held-out share is drawn separately from every dataset in a joint training collection so that each corpus is represented in validation.

\subsection{Evaluation Protocol}

We report SRCC and PLCC separately for every dataset. For multi-dataset experiments, macro SRCC and macro PLCC are computed by averaging the per-dataset correlations rather than pooling samples whose subjective scales and contents are not directly comparable; the worst per-dataset SRCC is also recorded. PIPAL is additionally evaluated using mean within-reference SRCC because its Elo scores rank restorations of the same source image and do not define an absolute ordering across different references. Conditioned models are compared with an independently trained image-only baseline under the same backbone, data split, and optimization settings. The intervention tests with wrong, shuffled, zeroed, and training-permuted conditions are reported in the corresponding experiment sections.

\section{Text Conditioning}

\subsection{Method}

In the text-conditioned experiments, every distortion group is represented by a short natural-language instruction describing the artefacts that should be assessed. For example, the blur prompt asks the model to assess lost sharpness, defocus, motion blur, and missing fine detail, while the authentic prompt asks for the overall perceptual quality of a real photograph. We encode these instructions once with the frozen text tower paired with the selected CLIP vision encoder. Both the pooled image feature and the text feature are layer-normalized and projected to 256 dimensions, so the text branch does not modify the frozen CLIP backbone.

We examined three elementary fusion rules. Concatenation gives the regressor $[v,t]$, interaction fusion gives it $[v,t,v\odot t]$, and the residual model adds a text-dependent correction to an unconditional image score. Here $v$ and $t$ denote the projected image and prompt embeddings and $\odot$ denotes elementwise multiplication. The image-only baseline retains the original pooled-feature head. The interaction term proved the most reliable of these alternatives and was therefore used in the later multi-dataset and multi-view experiments.

\subsection{KADID-10k Pilot}

The pilot experiments used CLIP-Base, the reference-based KADID-10k split, five training epochs, and seeds 0--2. Table~\ref{tab:text-kadid-fusion} reports the mean final-epoch correlations. Simple concatenation changed SRCC only slightly, whereas interaction fusion improved mean SRCC by 0.0248 and did so for every seed. The residual formulation also improved SRCC, but its PLCC gain was much smaller than that of interaction fusion.

\subsection{Multi-Dataset and Multi-View Experiments}

The principal text-conditioning experiment used the clean training mixture of KADID-10k, SPAQ, and AIGCIQA2023. It contains 18,945 training images and 4,705 validation images, sampled with equal expected weight per dataset. GFIQA-20k, PIPAL, TID2013, CSIQ, CID2013, KonIQ-10k, CLIVE, AGIQA-3K, and UHD-IQA form the nine-dataset external macro average for this experiment. We selected a checkpoint using validation macro SRCC and report means across seeds 0--2 for the central pooled and five-view text models.

The five-view model was introduced because a single center crop can remove local distortions or rescale them until they are difficult to recognize. It encodes one aspect-preserving global crop and four local tiles with the frozen CLIP encoder. The text interaction features $[v_i,t,v_i\odot t]$ determine a learned softmax weight for each view; the weighted visual representation is then fused with the prompt by the same interaction rule. The image-only multi-view control uses the same five views and learned weighting but omits the text branch, while a widened control approximately matches the conditioned head's parameter count.

Scaling the five-view text model to CLIP-Large improved validation correlation but did not improve the external macro average, suggesting that crop coverage and conditioning were more consequential for transfer than backbone size alone.

\section{Dataset Label Conditioning}

\subsection{Method}

Dataset label conditioning uses the known coarse distortion group directly rather than expressing it as natural language. Each of the eight groups is mapped to a learned 32-dimensional embedding. During training, 10\% of the conditions are zeroed so that the head also learns an unconditional fallback. The CLIP visual encoder remains frozen, and only the group embedding, fusion layers, and quality head are optimized.

We investigated several ways to inject the group embedding. Concatenation appends it to the normalized pooled CLIP representation; additive fusion projects it to the visual dimension and adds it to the image feature; input and hidden FiLM predict featurewise scale and shift parameters; and the residual-gate model predicts a condition-dependent correction to an unconditional score. Two exploratory variants were designed to keep the trainable parameter count close to the original head: a rank-4 hypernetwork generates a low-rank update to the first regression layer, while label-guided patch attention uses the group embedding as a query over frozen CLIP patch tokens. In all results in this section, the ground-truth dataset group is supplied at inference time, so these experiments measure the value of an oracle label rather than the performance of an automatic distortion recognizer.

\subsection{Single-Dataset Results}

Table~\ref{tab:label-kadid} compares the principal fusion rules on KADID-10k. The displayed checkpoint is the epoch with the best validation SRCC, which differs from the final-epoch convention used in the initial text-conditioning pilot. With CLIP-Base, the residual-gate head was the best label-conditioned variant, raising validation SRCC from 0.7548 to 0.7658 and the seven-dataset external macro SRCC from 0.4861 to 0.5230. The other fusion rules produced only small or inconsistent gains. With CLIP-Large, concatenation raised SRCC by 0.0047 while slightly reducing PLCC, again indicating that a label alone was not sufficient for a large and stable improvement.

\section{Classifier Label and Feature Conditioning}

\subsection{Distortion Classifier}

Oracle group labels are unavailable for arbitrary test images, so we trained an ImageNet-pretrained ResNet-18 to recognize the eight distortion groups. Its final classification layer was replaced by an eight-class output layer, and the network was trained on KADID-10k for 20 epochs with class-weighted cross entropy, AdamW, a learning rate of $10^{-4}$, weight decay $10^{-4}$, and batches of 64. The best validation accuracy was 88.6\%. We then supplied either the classifier's hard argmax label or its soft class-probability vector to a CLIP-Base quality head. In the frozen setting the classifier weights were fixed; in the joint setting the classifier and IQA head were optimized together with loss $L=L_{\mathrm{IQA}}+0.25L_{\mathrm{cls}}$.

\subsection{Predicted-Label Results}

Table~\ref{tab:classifier-labels} compares predicted labels with both an oracle-label upper bound and a zero-condition control using the same one-hidden-layer concatenation head. Ground-truth labels gave only a small improvement over the zero-condition control. Replacing them with predictions from the frozen classifier reduced both KADID-10k and external correlations, and soft probabilities did not correct the loss. Joint fine-tuning also failed to help. Classification accuracy therefore did not translate directly into a useful low-dimensional quality condition: mistakes in the discrete group and the removal of within-group severity information outweighed the modest oracle-label benefit.

Intermediate features were substantially more useful than predicted class labels. Directly normalized layer-4 features produced the strongest KADID-10k result in this experiment group, improving SRCC by 0.1274 over the capacity control, while projected layer-3 features gave the best external SRCC. The transfer gains were much smaller than the in-domain gain and varied sharply by dataset: for example, the layer-4 model obtained SRCC 0.8427 on CSIQ but only 0.0489 on UHD-IQA. We therefore interpret classifier features as a strong in-domain distortion representation, not as evidence that the eight-class classifier generalizes uniformly to unseen image domains.

\subsection{ARNIQA Feature Conditioning as a Side Result}

As a side experiment, we replaced the classifier representation with features from a frozen ARNIQA encoder. For every image, ARNIQA aggregates five spatial crops at full scale and five at half scale into a 4096-dimensional feature. This vector is layer-normalized, projected through a 32-dimensional GELU bottleneck, and concatenated with the frozen pooled CLIP feature before quality regression. This is no longer a minimal label-conditioning method: it adds a second IQA-oriented visual encoder and ten-crop processing, so its accuracy and computational cost must be interpreted separately from the lightweight group conditions.

ARNIQA features improved both CLIP backbones: KADID-10k SRCC increased by 0.1342 for CLIP-Base and 0.0513 for CLIP-Large, while external macro SRCC increased by 0.1116 and 0.0534, respectively. The inference interventions show that the auxiliary representation was actively used. For CLIP-Base, shuffling ARNIQA features among validation images reduced SRCC from 0.8890 to 0.6019 and zeroing them reduced it to 0.7524; for CLIP-Large, the corresponding values were 0.9191, 0.6943, and 0.8503. The standalone ARNIQA regressor remained strongest on KADID-10k, but CLIP-Base with ARNIQA conditioning gave the highest external macro correlation in this comparison. These results suggest that continuous distortion-aware features are much more informative than a hard group identity, although much of the gain comes with the cost and prior knowledge of an additional IQA encoder.
